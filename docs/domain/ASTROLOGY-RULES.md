# 命理規則與邊界

> 這份文件定義「我們採用什麼流派、怎麼算、哪些不顯示」。
> 改規則前，先看 `engineering/TESTING.md` 與金標準盤；不要為單一文案需求改引擎。

---

## 1. 流派

- 採用 **倪海厦《天紀》系的三合派** 紫微斗數
- 12 宮、14 主星、四化、大限、流年
- 格局以《紫微斗數全書》的〈定貴局〉〈定富局〉為主

### 宮位名稱

- 顯示用 **交友宮**
- 引擎內部 key 仍是 `仆役`
- 若未來要改「奴僕宮」，只改 `lib/{jp,zh}/glossary.ts` 的顯示名，不改引擎

---

## 2. 時間與排盤

| 項目 | 規則 |
|---|---|
| 時區 | 日本 JST（UTC+9）；港台 UTC+8 |
| 真太陽時 | 以 135°E（日本）／120°E（港台）校正 |
| 晚子時 | 23:00–23:59 視為次日排盤 |
| 未知時刻 | 以正午計算，畫面明確提示 |
| 農曆年 | 正月初一換年（紫微排盤用） |
| 節氣四柱 | 立春換年；引擎目前以中國標準時計算，**畫面不顯示四柱** |
| 流年 | 使用者選「讀取的年」，以曆年（1/1–12/31）為準；FAQ 說明流派差異 |

### 已知邊界

- 四柱若未來要顯示，需加 `utcOffset`，否則日本/港台在立春當天可能差一小時
- 春節/立春邊界目前是「曆年選擇器」，不是嚴格交節時刻
- 真太陽時只校正到分鐘級；極端時區/戰時夏令時未處理

---

## 3. 空宮

- 命宮、夫妻、官禄、財帛、田宅若空宮：
  - **顯示層**借對宮主星，明確寫「空宮，對宮的〇〇影響」
  - 四化、大限、流年仍按本命盤
- 不得捏造不存在的星曜
- 回歸：`jp-report`、`zh-content`

---

## 4. 明暗（廟旺利陷）

- 內部可能有 8 段（含「地」）
- 顯示統一為 **7 段：廟・旺・得・利・平・不・陷**
- 「地」→「平」
- 程式：`brightnessJa()` / `brightnessZh()`

---

## 5. 格局

### 已採用

- 〈定貴局〉27 格中，安星法上可能出現的正向格
- 〈定富局〉6 格中，可能出現的正向格
- 檔案：`lib/ziwei/patterns-dinggui.ts`、`patterns-dingfu.ts`
- 譯文：`lib/{jp,zh}/glossary.ts`
- 出典注記：《全書》對應格

### 未採用

- 〈定貧賤局〉8 格
- 〈定雜局〉8 格

理由：

- 格名否定了整個人（一生孤貧、生不逢時）
- 多為大限格，不適合放在本命盤
- 與「不製造恐懼」的產品原則衝突
- 景表法/消費者契約法的斷定風險

若未來要做，必須改寫成「課題/守成的時期」，並經專家確認。

### 邊界

- 格局是「傾向」不是「命運判決」
- 同一盤可能同時有多個格局；显示順序由 `facts` 決定
- 不要為了讓文案好寫而新增格局

---

## 6. AI 與命理

- 命盤由 `lib/ziwei/*` 計算，不經 LLM
- LLM 只讀 `facts digest`，不得新增星曜/宮位/四化
- 目前 digest 只含：命宮、夫妻、官禄、財帛、田宅、福德、遷移、五行局、命主/身主、大限、流年、四化、格局、三方四正
- **不含**：全部 12 宮、煞星/吉星、宮干、部分小星
- AI API 目前用「當前年份」，不支援使用者選的流年（已知缺口）
- AI 不得給醫療/法律/投資/賭博建議，不得斷定未來
