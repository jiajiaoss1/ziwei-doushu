# 命理规则与边界

> 这份文件定义「我们采用什么流派、怎么算、哪些不显示」。
> 改规则前，先看 `engineering/TESTING.md` 与金标准盘；不要为单一文案需求改引擎。

---

## 1. 流派

- 采用 **倪海厦《天纪》系的三合派** 紫微斗数
- 12 宫、14 主星、四化、大限、流年
- 格局以《紫微斗数全书》的〈定贵局〉〈定富局〉为主

### 宫位名称

- 显示用 **交友宫**
- 引擎内部 key 仍是 `仆役`
- 若未来要改「奴仆宫」，只改 `lib/{jp,zh}/glossary.ts` 的显示名，不改引擎

---

## 2. 时间与排盘

| 项目 | 规则 |
|---|---|
| 时区 | 日本 JST（UTC+9）；港台 UTC+8 |
| 真太阳时 | 以 135°E（日本）／120°E（港台）校正 |
| 晚子时 | 23:00–23:59 视为次日排盘 |
| 未知时刻 | 以正午计算，画面明确提示 |
| 农历年 | 正月初一换年（紫微排盘用） |
| 节气四柱 | 立春换年；引擎目前以中国标准时计算，**画面不显示四柱** |
| 流年 | 用户选「读取的年」，以历年（1/1–12/31）为准；FAQ 说明流派差异 |

### 已知边界

- 四柱若未来要显示，需加 `utcOffset`，否则日本/港台在立春当天可能差一小时
- 春节/立春边界目前是「历年选择器」，不是严格交节时刻
- 真太阳时只校正到分钟级；极端时区/战时夏令时未处理

---

## 3. 空宫

- 命宫、夫妻、官禄、财帛、田宅若空宫：
  - **显示层**借对宫主星，明确写「空宫，对宫的〇〇影响」
  - 四化、大限、流年仍按本命盘
- 不得捏造不存在的星曜
- 回归：`jp-report`、`zh-content`

---

## 4. 明暗（庙旺利陷）

- 内部可能有 8 段（含「地」）
- 显示统一为 **7 段：庙・旺・得・利・平・不・陷**
- 「地」→「平」
- 程序：`brightnessJa()` / `brightnessZh()`

---

## 5. 格局

### 已采用

- 〈定贵局〉27 格中，安星法上可能出现的正向格
- 〈定富局〉6 格中，可能出现的正向格
- 文件：`lib/ziwei/patterns-dinggui.ts`、`patterns-dingfu.ts`
- 译文：`lib/{jp,zh}/glossary.ts`
- 出典注记：《全书》对应格

### 未采用

- 〈定贫贱局〉8 格
- 〈定杂局〉8 格

理由：

- 格名否定了整个人（一生孤贫、生不逢时）
- 多为大限格，不适合放在本命盘
- 与「不制造恐惧」的产品原则冲突
- 景表法/消费者契约法的断定风险

若未来要做，必须改写成「课题/守成的时期」，并经专家确认。

### 边界

- 格局是「倾向」不是「命运判决」
- 同一盘可能同时有多个格局；显示顺序由 `facts` 决定
- 不要为了让文案好写而新增格局

---

## 6. AI 与命理

- 命盘由 `lib/ziwei/*` 计算，不经 LLM
- LLM 只读 `facts digest`，不得新增星曜/宫位/四化
- 目前 digest 只含：命宫、夫妻、官禄、财帛、田宅、福德、迁移、五行局、命主/身主、大限、流年、四化、格局、三方四正
- **不含**：全部 12 宫、煞星/吉星、宫干、部分小星
- AI API 目前用「当前年份」，不支持用户选的流年（已知缺口）
- AI 不得给医疗/法律/投资/赌博建议，不得断定未来
