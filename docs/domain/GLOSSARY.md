## 3. 使用规则

1. 繁中版用台湾用词，示例：`網路`、`影片`、`軟體`、`螢幕`（保留繁体，不要写成大陆用词）
2. 日文版用 です・ます，不用简体字
3. 同一页不要混用「命盤/星盤」「鑑定/解讀」等不同说法
4. 新术语先加这张表，再写进文案
5. 命理术语的显示名以 `lib/{zh,jp}/glossary.ts` 为准
