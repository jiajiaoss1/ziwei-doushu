## 3. 使用規則

1. 繁中版用台灣用詞（網路、影片、軟體、螢幕）
2. 日文版用 です・ます，不用簡體字
3. 同一頁不要混用「命盤/星盤」「鑑定/解讀」等不同說法
4. 新術語先加這張表，再寫進文案
5. 命理術語的顯示名以 `lib/{zh,jp}/glossary.ts` 為準
