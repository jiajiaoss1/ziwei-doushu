# ADR-0001 根路径改为 `/zh`

- 日期：2026-11-21
- 状态：Accepted
- 批准人：负责人

## 背景

紫微馆同时有日文 `/ja` 与繁中 `/zh`。需要决定根路径给哪个市场。

## 选项

1. `/` → `/ja`（日本优先）
2. `/` → `/zh`（港台优先）
3. `/` 做语言选择页

## 决定

`/` → **307 `/zh`**（`shibikan.com` / `www`）。

## 理由

- 港台是目前主推市场
- 台湾对倪海厦/紫微斗数认知度高
- 繁中版功能与内容较完整
- 日文版仍保留 `/ja`

## 后果

- 日文版不是默认入口，SEO 以 `/zh` 为主
- 未来若日本优先，需新 ADR，不要直接改
- 根路径在 `next.config.js` 以 host 判断
