# ADR-0001 根路徑改為 `/zh`

- 日期：2026-11-21
- 狀態：Accepted
- 批准人：负责人

## 背景

紫微館同時有日文 `/ja` 與繁中 `/zh`。需要決定根路徑給哪個市場。

## 選項

1. `/` → `/ja`（日本優先）
2. `/` → `/zh`（港台優先）
3. `/` 做語言選擇頁

## 決定

`/` → **307 `/zh`**（`shibikan.com` / `www`）。

## 理由

- 港台是目前主推市場
- 台灣對倪海厦/紫微斗數認知度高
- 繁中版功能與內容較完整
- 日文版仍保留 `/ja`

## 後果

- 日文版不是預設入口，SEO 以 `/zh` 為主
- 未來若日本優先，需新 ADR，不要直接改
- 根路徑在 `next.config.js` 以 host 判斷
