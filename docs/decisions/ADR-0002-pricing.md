# ADR-0002 定價

- 日期：2026-11-21
- 狀態：Accepted
- 批准人：负责人

## 決定

### 繁中（港台）

- 感情鑑定書：NT$680 / HKD160
- 事業鑑定書：NT$980 / HKD230

### 日文（日本）

- 恋愛鑑定書：¥2,980（無料）
- 事業鑑定書：¥4,980

## 理由

- 港台以台幣/港幣雙顯示，降低跨境摩擦
- 感情較低價，適合第一次購買
- 事業較高價，反映決策價值
- 日文版戀愛免費，作為引流

## 後果

- β 期間全免費，價格僅展示
- 改價需更新 `lib/zh/pricing.ts` / `lib/jp/access.ts`、首頁、報告頁、法務頁
- 不提供假折扣/假原價
