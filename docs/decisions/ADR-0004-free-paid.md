# ADR-0004 免费/付费边界

- 日期：2026-11-21
- 状态：Accepted
- 批准人：负责人

## 决定

| 市场 | 免费 | 付费 |
|---|---|---|
| 繁中 | 免费诊断（命盘/本质/感情/工作/今年） | 感情报告、事业报告 |
| 日文 | 免费诊断 + 恋爱报告 | 事业报告 |

β 期间 `JP_BETA_FREE=true`，全部免费；收费后照上表。

## 理由

- 繁中感情/事业都有付费意愿（定价已定）
- 日文以恋爱免费引流、事业变现
- 免费诊断仍是获客核心

## 后果

- 免费版不能给完整付费价值
- 付费报告必须提供「免费没给的 job」
- 变更需新 ADR + Owner 批准
