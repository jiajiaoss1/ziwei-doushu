# ADR-0004 免費/付費邊界

- 日期：2026-11-21
- 狀態：Accepted
- 批准人：负责人

## 決定

| 市場 | 免費 | 付費 |
|---|---|---|
| 繁中 | 免費診斷（命盤/本質/感情/工作/今年） | 感情報告、事業報告 |
| 日文 | 免費診斷 + 戀愛報告 | 事業報告 |

β 期間 `JP_BETA_FREE=true`，全部免費；收費後照上表。

## 理由

- 繁中感情/事業都有付費意願（定價已定）
- 日文以戀愛免費引流、事業變現
- 免費診斷仍是獲客核心

## 後果

- 免費版不能給完整付費價值
- 付費報告必須提供「免費沒給的 job」
- 變更需新 ADR + Owner 批准
