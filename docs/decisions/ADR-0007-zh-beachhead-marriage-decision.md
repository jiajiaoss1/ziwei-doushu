# ADR-0007 ZH 首发定位：婚姻关系决策 × 已试过命理者

- 日期：2026-11-21
- 状态：Accepted
- 批准人：负责人

## 背景

ZH 当前的问题是「用户看完网站，购买欲望低」：

- 目标人群太宽（感情、事业、年度都讲一点）
- 免费内容/免费 AI 与付费报告重叠
- 付费报告是「更多章节」，不是不同的 job
- 信任证据不足，价格/退款不透明

Threads pilot V1–V3（533 条合并数据、28 条试编码）给出方向性信号：

- A 组（自然痛点）数量多，但多数停在 E1，不能直接证明付费
- B 组（命理消费）有 E2 推荐/价格/信任，但 E3 很少
- 婚姻/长期关系比单纯分手更像付费场景
- 最强信任异议：怕被骗、怕不准、不知道怎么问、行业收费乱
- HK 样本不足

## 选项

| 选项 | 说明 | 判断 |
|---|---|---|
| A. 婚姻/长期关系决策者 | 外遇怀疑、分居、公婆、沟通疏离、离婚犹豫 | 痛点强、决策成本高 |
| B. 30–45 岁转职/裁员者 | 裁员、35 岁转职、转职落差 | 痛点明确，但付费证据弱 |
| C. 已试过命理但失望的人 | 被坑、十种说法、价格乱、已付费不会问 | 有付费习惯、信任异议强 |
| **A × C** | 正在做婚姻/长期关系重大决定，已试过朋友/塔罗/宫庙/老师仍不满意 | **选中** |

## 决定

### 1. Beachhead 与市场

- 首发只做**台湾**
- 先隐藏 HK
- ICP：**30–42 岁女性**
- Beachhead：**A × C 交集**
- 事业线只做内容/第二场景，不进首发付费

### 2. 品类与承诺

- 品类：**關係決策分析**
- 产品：**關係決策書**
- 承诺：**幫你形成決定，也告訴你怎麼做**
- 首页主标题：**用命盤，把關係的混亂整理成可以做的決定。**

### 3. 产品与交付

- 一次性购买，不做订阅
- 价格：**NT$680 早鸟 → 恢复 NT$980**
- 报告 6 部分：
  1. 决策问题
  2. 关系模式
  3. 选项分析
  4. 沟通脚本
  5. 时机
  6. 1–3 追问
- 网页版报告，付款后立即生成，可回看 **1 年**（付款起算）
- 报告放命盘图，只标注关键宫位
- 报告后 1–3 个追问，**14 天**内有效（首次打开起算）
- 追问由 AI 回答；敏感/超范围直接拒绝，**不转人工**
- 退款：7 天内、**未打开报告**可退

### 4. 免费/付费边界

- 免费：**關係決策自查 + 规则化问题澄清**
- 自查只收**年月日**
- 自查结果：3 个判断 + 1 个下一步建议
- 自查结果标注「未含時辰，僅供初步整理」
- 必须先做自查，才能购买
- 付费时才补：**时辰 + 出生县市**
- 不知道时辰：可选「不知道」，用午时，同价并标注
- 完整命盘解读只在付费

### 5. 信任与表述

- 首页主位：**用户口吻评价**（当前为草案，beta 后换真实评价）
- 页面主文案**不强调 AI**，只讲命盤
- 用「科技輔助」
- 方法说明/细字如实说明：命盘由系统计算，解读有规则与边界
- 不声称真人老师
- 不承诺准确率/命中率/复合结果

## 理由

1. 婚姻/长期关系的决策成本高于普通恋爱，用户要的是「判断 + 怎么谈」，不是运势。
2. C 组有付费习惯与明确信任异议，适合用「可信、透明、不推销」切入。
3. 只卖一个 SKU，才能把首页、免费自查、报告、追问讲成一条线。
4. 台湾首发，避免用不足的 HK 样本做错误本地化。
5. 免费自查只收年月日、付费补时辰，兼顾低门槛与命盘质量。

## 后果

- **部分取代 ADR-0002（ZH 定价结构）**：ZH 首发不再同时卖感情/事业两个 SKU；JA 定价不变。
- **部分取代 ADR-0004（ZH 免费/付费边界）**：ZH 免费改为「自查 + 规则化澄清」；JA 不变。
- ADR-0003（AI 角色）仍有效：AI 受命盘事实约束；本 ADR 只调整对外表述。
- 需要同步：`PRD-ZH`、报告 SPEC、首页 SPEC、支付/退款实现、GA4 事件。
- HK 页面先隐藏；HK 样本足够后再开新 ADR。
- 必须做 8–12 个访谈，验证「婚姻决策者愿意为决策书付费」。

## 未决

- HK 是否/何时开
