# 紫微館 内部レビュー（用語・表示・法務の暫定判断）

> 日付：2026-11-16 ／ 範囲：第2版校閲で残った確認事項の整理
> 立場の明示：本レビューは **エンジニアリング／プロダクト判断** であり、日本の弁護士資格・紫微斗数の認定鑑定士資格に基づくものではありません。法務は最終的に専門家確認が必要です。

## 1. 宮位名：「交友宮」を採用

- 本サービスは倪海厦『天紀』系の三合派を採用しており、十二宮は **交友宮** を用います。
- 「僕役宮」「奴僕宮」は古い呼称・飛星派寄りの表記で、日本語の一般的な紫微斗数書では「交友宮」が通りやすい。
- エンジン内部のキーは `仆役` のまま（表示だけ交友宮）。流派変更時は `lib/jp/glossary.ts` の `nameJa` 1行で切替可能。

## 2. 星の明暗：表示は7段階、「地」は「平」に寄せる

- エンジンは XD1 系の拡張段階「地」を返すことがあるが、日本語の一般的な表示は **廟・旺・得・利・平・不・陷** の7段階。
- 内部データは保持し、表示時のみ `地 → 平` に変換（`brightnessJa()`）。
- 記事中の「廟・旺・利・陷」は代表例としての言及で、実装は7段階。

## 3. 空宮の扱い：表示だけ対宮を参照

- 命宮・夫妻宮・官禄宮・財帛宮・田宅宮が空宮の場合、**対宮の主星を「借りて」表示**する。
- ただし四化・大限・流年の計算は本命盤のまま。空宮を理由に星を捏造しない。
- 旧実装は空宮で星名が空になり「命宮にはが座っています」と出力していた。`lib/jp/report.ts` / `interpret.ts` / `compat.ts` を修正し、`jp-report` 回帰テストで担保。

## 4. 流年の切替：暦年セレクタとして表示

- 本サービスの「読む年」は **暦年（1/1〜12/31）** のセレクタ。四化はその年の天干で計算する。
- 旧正月（春節）や立春を境に切り替える流派もあるため、FAQ にその旨を明記。
- 2027年は丁未、春節は 2027-02-06（`lunar-javascript` で確認）。
- 春節境界を厳密に実装する場合は、選択年ではなく「基準日」を持たせる設計変更が必要（現状は未実装）。

## 5. 法務・表記

- **特定商取引法**：事業者名・所在地・電話・返品条件は「準備中」。有料提供開始前に確定。
- **支払方法**：Stripe は占いを禁止しているため「決済代行会社経由」と表記。実際の PSP が決まった時点で差し替える。
- **プライバシー**：「DBに保存しない＝保存されない」と誤解させないよう、URLパラメータ・アクセスログ・ブラウザ履歴・解析ツールの可能性を明記。
- **返品**：即時「返品不可」と断定せず、提供方法・契約内容に応じて定める表現に変更。
- **連絡先**：`support@example.com` はご指示どおり暫定のまま。公開前に実在アドレスへ差し替える。
- 景表法・消費者契約法（断定的判断の提供、霊感商法規制）に触れる表現は引き続き排除。

## 6. 残リスク

1. 日本語の最終読み：第2版の主要箇所は反映済みだが、動的テンプレートの細かな言い回しは再度の通読が望ましい。
2. 法務：特商法・ privacy・退款は日本の専門家確認が必要。
3. 命理：空宮・四化・流年の境界は、採用流派の金標準盤で追加検証する余地あり。
4. 境界盤：空宮（官禄）、複数主星、晚子時のサンプルを回帰テストに追加済み。さらに年齢境界・節気境界の盤を追加するとよい。
