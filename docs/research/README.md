# 研究资料

> 研究的目的不是「证明命理准」，而是理解用户的决策、语言、购买阻力。

## 1. 规则

- 只收集公开资料；不碰私讯/非公开社群
- 原始资料（URL/原文）放 `research/data/raw/`，**不进 Git**
- 对外报告要匿名化、摘要化，不大量转载
- 遵守平台条款/频率限制，不绕过登录/CAPTCHA
- 每份研究要写：样本、搜寻词、期间、限制

## 2. 目前研究

| 文件 | 状态 | 用途 |
|---|---|---|
| `threads-pain-points-brief.md` | V2 / ready | Threads 首个付费用户群体研究 |
| `threads-pain-points-findings.md` | 待产出 | 研究结论 |

## 3. 新增研究

1. 在 `research/` 建 `<topic>-brief.md`
2. 用 `AGENT-CONTRACT` 的规则，写清任务/样本/栏位/交付物
3. 执行后建 `<topic>-findings.md`
4. 把结论回写到 `product/POSITIONING.md` / `PRD-*.md`
5. 在 `operations/CHANGELOG.md` 记一笔

## 4. 研究结论的用法

- 只能用来**支持/修正假设**，不是直接当需求
- 要能回答「这会改变哪个决策？」
- 不要用单一爆款贴文代表整个市场
