# Threads 痛點與購買動機調査ブリーフ

> 対象：Threads 上の公開投稿を調査する agent
> 目的：产品/文案向けの「生の痛點・決策語言・購買觸發・異議」を集める
> 更新日：2026-11-21
> ステータス：Draft（负责人确认后执行）

---

## 0. あなたのタスク（最初に読む）

あなたは「紫微館」のユーザーリサーチャーです。  
Threads の**公開**投稿・返信を調査し、港台（台灣・香港）のユーザーが

- どんな状況で
- どんな言葉で悩み
- 何を決められず
- 何にお金を払い、何に払わないか

を、**原文のニュアンスを保ったまま**整理してください。

これは「紫微斗数が当たるか」を検証する調査ではありません。  
**購買欲望が生まれる瞬間と、その言葉**を見つける調査です。

### 最初に読むもの

1. このブリーフ
2. `docs/handover.md`（プロダクトの現状）
3. `docs/ja-backlog.md`（既知の課題）

### 納品物

1. `docs/research/threads-pain-points-findings.md`（分析レポート）
2. `docs/research/data/threads-posts.csv`（匿名化済みコード表）
3. 生データ（URL・原文）は `docs/research/data/raw/` に保存し、**Git にはコミットしない**

---

## 1. 調査の目的

以下の4問に答える。

1. ユーザーはどんな**出来事**の直後に相談・検索・占いを求めるか？
2. そのとき、**どんな言葉**で痛みを表現するか？
3. すでに何を試し、何に失望し、何を恐れているか？
4. どんな**証拠・約束・提示**があれば NT$680 / NT$980 を払うか？

### 特に知りたいこと

- 「感情の決斷」と「仕事の決斷」で、痛みの質はどう違うか
- 「占いにお金を払う」ときの**最後の一押し**は何か
- 「AI でいいや」と思う瞬間と、その理由
- 「怪怪的/被騙/不準」と感じる理由
- 価格に対して、何と比較しているか（食事・心理諮商・塔羅・友達）

## 2. サンプル範囲

| 項目 | 指定 |
|---|---|
| プラットフォーム | Threads の公開投稿・公開返信 |
| 言語 | 繁體中文（台灣・香港の用詞） |
| 期間 | 直近3か月（2026-08-21 〜 2026-11-21） |
| 目標件数 | 投稿 200〜300、返信 500+（まず100投稿で飽和確認） |
| 地域 | 台灣・香港。日本語・簡体字は別ファイルに分ける |
| 収集方法 | 公開検索・公開投稿のみ。ログイン必須の非公開領域は対象外 |

### サンプリング方針

- **痛みクラスタ4種**を均等に集める  
  1. 感情（曖昧・復合・別離・結婚）
  2. 仕事（転職・退職・創業・昇進）
  3. 占い/支払い（紫微・塔羅・月老・霊能・価格・被骗）
  4. 決策語言（該不該・要不要・卡住・內耗）
- 投稿だけでなく**返信**も集める（購買意図は返信に出やすい）
- エンゲージメント上位だけに偏らせない（無名の切実な投稿も重要）
- 同じユーザーの重複投稿は1件にまとめる

## 4. 包含・除外

### 含める

- 本人が現在経験している具体的な状況
- 明確な decision question がある（復合すべき？辭職すべき？）
- 感情・時間圧・金銭/関係コストがある
- 公開投稿で、文脈が読める

### 除外

- 占い師・タロット師の広告、集客、無料鑑定の宣伝
- ニュース、ミーム、画像だけ、本文なし
- 他人のプライバシーを強く特定できる内容
- 簡体字（必要なら `language=zh-Hans` で別管理）

## 5. 記録フォーマット

`docs/research/data/threads-posts.csv` に以下の列で保存。

```csv
post_id,url,platform,posted_at,collected_at,query,post_type,
language,region_signal,author_bio_public,
text_verbatim,situation_summary,decision_question,
relationship_stage,work_stage,
pain_cluster,emotion,urgency,
prior_solutions,paid_before,price_signal,trust_objection,desired_outcome,
engagement_likes,engagement_replies,notes
```

### 各列の定義

| 列 | 定義 |
|---|---|
| `post_id` | 平台内 ID（不明なら URL のハッシュ） |
| `url` | 公開投稿 URL（内部用。レポートでは出さない） |
| `post_type` | `original` / `reply` / `quote` |
| `language` | `zh-Hant` / `zh-Hans` / `mixed` |
| `region_signal` | 台灣用詞、香港用詞、地名、幣別（例：`TW`, `HK`, `unknown`） |
| `author_bio_public` | 公開プロフィールに書かれた属性のみ。空欄可 |
| `text_verbatim` | 原文。改変しない（匿名化は別列/レポートで） |
| `situation_summary` | 1〜2文の要約。原文をコピーしない |
| `decision_question` | 本人が決めたいこと（例：復合するか、辭職するか） |
| `relationship_stage` | `single` / `ambiguous` / `dating` / `committed` / `married` / `breakup` / `na` |
| `work_stage` | `student` / `employed` / `job-hunting` / `considering-quit` / `founder` / `na` |
| `pain_cluster` | 下記コードブックの複数可（`;` 区切り） |
| `emotion` | `anxiety` / `confusion` / `shame` / `hope` / `anger` / `numb` |
| `urgency` | `now` / `weeks` / `months` / `unknown` |
| `prior_solutions` | 友人・塔羅・紫微・心理諮商・ChatGPT など（`;`） |
| `paid_before` | `yes` / `no` / `unknown`（占い・相談に支払ったか） |
| `price_signal` | 価格への言及（高い/安い/いくらなら払う） |
| `trust_objection` | `怕不準` / `怕被騙` / `隱私` / `覺得貴` / `不信命理`（`;`） |
| `desired_outcome` | `answer` / `timing` / `action` / `comfort` / `validation` |
| `engagement_likes` | 取得時点の数 |
| `engagement_replies` | 取得時点の数 |
| `notes` | 文脈・例外・検索語など |

> `text_verbatim` は内部保存のみ。対外レポートでは匿名化・要約・短い引用に留める。

## 6. コードブック（初期版）

### 痛みクラスタ（12〜15）

```
關係：不確定對方想法
關係：復合/挽回
關係：曖昧卡住
關係：結婚時機
關係：遠距/跨國
關係：背叛/劈腿
關係：放下/失戀
工作：轉職猶豫
工作：留任痛苦
工作：創業/副業恐懼
工作：升遷/人際瓶頸
工作：裁員/失業
自我：內耗/反覆思考
自我：選擇困難
金錢：怕花錢/怕被騙
```

### 異議（5）

```
怕不準
怕被騙
覺得貴
隱私顧慮
不相信命理
```

### 望む結果（5）

```
要一個答案
要時機
要具體行動
要被理解/安慰
要驗證自己想的對不對
```

### ルール

- 1投稿に複数コード可
- コードは `text_verbatim` を読んで付ける（要約だけで判断しない）
- 迷ったら `notes` に「なぜ迷ったか」を書く
- 10% は人間が再確認する前提で、判断根拠を残す

## 7. 作業手順

1. `docs/handover.md` とこのブリーフを読む
2. 検索語ごとに公開投稿を収集（まず各語 20 件）
3. 包含/除外でフィルタ
4. `threads-posts.csv` に記録
5. 100 件時点で saturation を確認（新しい痛みが出なくなったか）
6. 足りなければ 200–300 件まで追加
7. コードを付け、頻度・強度・支払い意欲でクラスタを整理
8. `threads-pain-points-findings.md` を書く
9. 生データは `data/raw/`、CSV は匿名化して保存
10. 完了後、`docs/handover.md` のタイムラインに1行追加

## 8. 最終レポートの構成

`docs/research/threads-pain-points-findings.md`:

1. **要約**（5 bullets）
2. **調査方法**（検索語・期間・件数・除外・限界）
3. **Top 20 痛點**（頻度 × 情緒強度 × 支払い意欲）
4. **痛點クラスタ別の原文**（各 5–10 件、匿名化）
5. **ユーザージャーニー**（trigger → search → compare → objection → purchase/abandon）
6. **セグメント矩阵**（感情/仕事 × 急迫/様子見 × 価格敏感/価値敏感）
7. **購買を止める理由 Top 5**
8. **刺さる言葉・NG 表現**
9. **検証したい仮説 10 件**
10. **限界と次に取るべきデータ**（Dcard/IG/インタビュー）

### レポートに必ず書くこと

- 件数と検索語（再現できるように）
- サンプルバイアス（Threads は若年・文字表現・特定コミュニティに偏る）
- 原文をそのまま大量転載しない（匿名化・要約）
- 「占いが当たる」という結論は書かない

## 9. 品質・倫理

- 公開情報のみ。DM・非公開コミュニティ・ログイン必須領域は対象外
- プラットフォームの利用規約・レート制限を守る
- ログインや CAPTCHA を回避しない。必要なら手動収集に切り替える
- ユーザー名・URL は内部管理のみ。レポートでは匿名化
- センシティブな内容（病名・暴力・未成年）は要約で扱い、原文を残さない
- 取得日時を記録し、数値は「取得時点」と明記
