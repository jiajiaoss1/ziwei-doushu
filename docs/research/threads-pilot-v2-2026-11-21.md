## 3. 关键发现

### 3.1 B 组终于出现可用的 E2 集群

`算命推薦` 的 5 条全部高相关：

- 新北：求“够准”的老师，价格不贵、准确率高、怕花冤枉钱
- 台南：算命改名，指定生肖、不要笔划
- 事业/财运/感情都不顺，问哪里准
- 高雄：想算命/问事，主要好奇感情
- 台中/台北：想算明年流年，问会不会太早

共同点：

- **E2 主动找方案**
- 有地区、价格、信任条件
- 不是“随便看看”，是准备花钱

### 3.2 价格与信任开始具体

- 鸟卦：补人缘 **3800 TWD**，用“不补会变忧郁”施压 → 恐惧诉求 + 价格 + 犹豫
- 香港：算命收费 **3000–5000 HKD**，讲完没内容还推销上万风水阵 → 行业价格乱 + 信任崩塌
- 新北：明确“价格不贵、准确率高、怕花冤枉钱”
- 流年：觉得今年不准，想换一个“准的”老师

这些比“用户有痛点”更接近购买决策。

### 3.3 A 组仍然以 E1 为主

A 组高相关样本：

- 待十几年被裁
- 转职第一天想离职
- 46 岁被资遣、想去职训
- 30 岁职涯徬徨
- 分手/前任
- 婚姻/育儿想离婚
- 公司突然开 HR/法务会议

但大多数是**抒发/求共鸣**：

- E1：8
- E2：2（46 岁资遣、婚姻想离婚）
- E3/E4：0

结论不变：**A 组适合内容/引流，不能直接证明付费。**

### 3.4 购买触发事件

目前最清晰的触发：

1. **裁员/公司重整**（待十几年被裁、HR 法务突然开会）
2. **转职落差**（第一天想离职、46 岁被资遣）
3. **分手/前任**（删合照、分手后哭）
4. **婚姻/育儿卡住**（想离婚、家庭沟通）
5. **年末/明年流年**（今年不准、想算明年）
6. **反复算命仍不满意**（“今年不準”、想换老师）
7. **被恐惧诉求推销**（鸟卦 3800、不补会忧郁）

### 3.5 信任异议

- 怕花冤枉钱
- 怕不准
- 怕被推销/被骗
- 不知道怎么问（已付费但不会问工作/财）
- 行业价格乱（3000–5000 HKD、上万风水阵）

### 3.6 香港仍然弱

- 只有 1 条高相关 HK 行业价格样本
- `香港算命`/`香港塔羅` 多数是从业者广告、课程、驻点服务
- 不能做 TW/HK 对比
- 需要单独搜消费者语言，而不是“香港算命”这种服务类目词

### 3.7 ChatGPT 搜索失败

`ChatGPT` 返回英文科技内容，不是中文命理讨论。
下一轮删除该词；AI 替代行为靠访谈，或改搜 `AI算命` / `AI占卜`（本轮 `AI算命` 0 条近期高相关）。

## 4. 对产品的启示（暂定）

1. B 组用户不是“想要更多预测”，而是：
   - 想找**可信、价格透明、不推销**的人
   - 想知道**怎么问**、怎么用这份报告
   - 想避免**再被坑一次**
2. 付费交付物可以围绕：
   - 购买前的“问题诊断/怎么问”
   - 一致、可解释的报告
   - 报告后的追问
3. A 组痛点适合做免费内容/引流，但付费墙不能只卖“更多章节”。
4. 价格不是唯一阻力；**信任 + 会不会用**更关键。

## 5. 对 codebook/搜索词的修正

### 保留并加强

- `算命推薦`（最高信号）
- `流年`（年末需求）
- `命盤`（已付费不会问）
- `香港算命` / `香港塔羅`（但只作补充）
- `AI算命`（低量，保留观察）

### 删除/降级

- `ChatGPT`（英文噪音）
- `被騙`（政治/生活噪音多，只作补充）
- `分手`（新闻/政治噪音多，需人工筛）

### 新增

- `算命 推薦` 已被验证；下一轮可加 `問事`、`改名`、`塔羅 推薦`
- 香港消费者词：`香港 算命 價錢`、`香港 塔羅 推薦`（若多词失败，用单词+本地筛选）
