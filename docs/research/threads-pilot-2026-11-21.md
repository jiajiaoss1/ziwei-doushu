# Threads pilot 20 条

> 目的：用现有 scraper 数据做一次小规模试编码，校准 V2 brief 的字段与关键词。
> 这不是正式样本，不能用来推断市场规模或付费率。

## 1. 数据来源与筛选

原始文件：`dataset_threads-scraper_2026-11-21_03-27-51-637.csv`

- 423 条帖子，18 个搜索词 × 约 25 条
- 语言：`zh_TW` 299、空 51、`ja` 39、`en` 18、`zh_CN` 16
- 时间：2024-05 ～ 2026-11

初筛：

- 只要 `zh_TW`
- 只要主帖（`isReply=false`）
- 2026-08-21 之后
- 文本 ≥30 字

结果：164 条。
再按“第一人称痛点/决策/付费信号”严格过滤：

- A 组（自然痛点）14 条
- B 组（命理消费）3 条

**严格筛完不足 40 条。**
为了不注水，最终人工选了 **20 条**：

- A 组 14 条（高/中相关 10 条）
- B 组 6 条（高/中相关 5 条）
- 高相关 11、中 4、低 3、负样本 2

编码表（本地、未提交）：

## 3. 发现

### 3.1 A 组：痛点很多，但大多停在 E1

A 组的高相关样本主要是：

- 分手后仍走不出来
- 职场人际消耗
- 转职/离职后的不安
- 复合的可能
- 迷惘、需要方向

但绝大多数是**抒发**，不是主动找方案：

- E1：11 条
- E2：3 条
- E3/E4：0 条

这验证了 review 的判断：**痛点频率 ≠ 付费意愿**。
如果把 A 组痛点直接当市场机会，会高估付费。

### 3.2 B 组：真正有付费证据，但样本老、且被广告污染

B 组最有价值的是 4 类：

1. **被坑型 E3**
   想找“准的”老师，之前被騙过几次，有一次花 3000 元。
   → E2 + E3 + 信任异议（怕被騙），是最强购买/信任样本。

2. **预算型 E2**
   求推荐老师，预算 600–2000 元。
   → 明确价格区间，说明“价格”不是完全不能接受，关键是信任与效果。

3. **反复尝试型 E3**
   以前很爱算命，乩童/通灵/塔罗/八字都试过，后来觉得“十个老师十种说法”，不再算。
   → 这是“替代方案不满意”的典型，也是产品机会：一致性、可解释、可反复查看。

4. **已付费但不会问型 E3**
   第一次给真人看命盘，不知道该怎么问工作/财的问题。
   → 用户缺的不是“更多信息”，而是“怎么把问题问对/怎么用这份报告”。

这些样本大多在 2024–2026-02，不在最近 3 个月；说明**近期 B 组搜索词被从业者广告占据**。

### 3.3 关键词问题

- `紫微斗數`、`命盤`、`流年`：大量老师/课程/App/服务广告
- `算命`、`塔羅`：大量从业者内容、大众占卜、娱乐
- `感情困擾`、`職涯迷惘`：混入心理咨询、职涯教练、陪聊服务

结论：
**自然痛点组不能只搜“命理词”，B 组也不能只搜“服务类目词”。**
B 组要搜“体验/价格/被骗/推荐/后悔”这类**消费决策语言**。

### 3.4 没有香港样本

20 条全部标记 `region=unknown`、`region_confidence=low`，只有 `zh_TW` 语言标记。
不能做 TW/HK 对比，也不能假装有 HK 样本。

### 3.5 回复不能用

93 条 `isReply=true`，但 `replyToPostId` 全空。
脱离父帖编码会误判，所以 pilot 只选主帖。

### 3.6 ChatGPT 提及很少

全量 423 条里只有约 3 条提到 ChatGPT/AI 算命，且没有高相关购买样本。
说明：

- Threads 上“AI 替代命理”的讨论密度低
- 不能只靠 Threads 研究 AI 替代行为
- 必须靠访谈补

## 4. 对产品的启示（暂定）

1. **A 组痛点适合做内容/引流，但不适合直接证明付费。**
2. **B 组的付费用户更像“被坑过、试过很多、仍不满意”的人。**
   - 他们要的不是“更多神准”，而是：
     - 可解释
     - 一致
     - 不骗
     - 知道怎么问/怎么用
3. **付费交付物可以围绕“把问题问对 + 一致的解释 + 可执行下一步”设计。**
4. **价格不是唯一阻力；信任和“值不值”更重要。**
5. **免费 AI 的替代行为在 Threads 上证据不足，不能据此做产品决策。**

---

## 5. 对 V2 brief 的修正建议

1. B 组关键词增加消费决策词：
   ```
   被騙 算命 / 算命 價格 / 推薦 老師 / 算命 經驗 / 算過 後悔 / 不準 算命
   ```
2. 香港单独搜：
   ```
   香港 算命 / 香港 塔羅 / 香港 感情諮詢
   ```
3. 正式采集前，先用 20 条校准 codebook：
   - E3 的“被騙/花錢”是否能稳定识别
   - “职涯教练广告”和“真实转职痛点”是否能分开
4. 回复要么重新抓父帖，要么不纳入。
5. 40 条 pilot 不现实；**20 条高相关 pilot + 后续定向补样**更诚实。
