# 紫微馆 PRD — 共同产品定义

> 这份文件只写「跨市场不变的事」。
> 各市场的定位、定价、页面与需求，见 `PRD-ZH.md` / `PRD-JA.md`。
> 未来韩语、越南语版新增 `PRD-KO.md` / `PRD-VI.md`，不修改本文件的市场假设。

---

## 1. 产品一句话

**用紫微斗数的命盘，帮用户把「我现在卡住的事」看得更清楚，并给出可执行的下一步。**

不是「预测未来」，不是「保证灵验」，也不是「通用 AI 聊天」。

---

## 2. 产品边界

### 做

- 根据出生年月日、时刻、出生地排出紫微斗数命盘
- 把命盘转成用户能理解的语言（本质、感情、工作、金钱、大限、流年）
- 提供免费解读与付费深度报告
- 提供相性、年度主题、文章等辅助内容
- 用 AI 做「受命盘事实约束」的追问与解释

### 不做

- 医疗、法律、投资、赌博的专业建议
- 保证未来结果、命中率、一定复合/一定升职
- 用恐惧、诅咒、灾难预言促使购买
- 编造用户好评、假见证、假案例
- 未经同意的私讯/个资收集
- 把 `docs/tianji-ziwei/` 的原话大量翻译或直接对外展示

---

## 3. 共通用户旅程

```text
入口（首页/文章/搜寻/社群）
  → 免费诊断（生日、时刻、出生地、烦恼/情境）
  → 结果页（命盘、免费解读、共情、AI 追问）
  → 付费报告（感情/事业；β 全免费）
  → 解锁/付款
  → 售后（退款、客服、回访）
```

每一段都必须回答一个问题：

| 阶段 | 用户问题 | 产品要给什么 |
|---|---|---|
| 入口 | 这是什么？跟我有关吗？ | 一句话价值 + 具体情境 |
| 诊断 | 为什么要填这些？ | 低摩擦、隐私说明、时间不明选项 |
| 结果 | 这在说我吗？ | 具体、共情、可验证的命盘依据 |
| 付费 | 为什么要付？ | 免费没给的决策/行动/时机 |
| 售后 | 买了之后呢？ | 可保存、可重读、可退款/客服 |

## 4. AI 政策（跨市场）

### 4.1 AI 的角色

AI 不是「算命师」，是**解读层**：

- 命盘由 `lib/ziwei/*` 确定性计算
- `facts` 层把命盘整理成结构化事实
- LLM 只根据这些事实，产生受约束的说明
- AI 不得新增命盘中不存在的星曜、宫位、四化

### 4.2 对外说法

可以说：

> 命盘由排盘引擎计算，AI 只根据这张命盘的事实来整理解读。

不要说：

- 「比 ChatGPT 更准」
- 「AI 保证灵验」
- 「命中率 98%」
- 「大师亲算」（如果没有真人）

### 4.3 免费/付费的 AI 边界（方向）

- 免费 AI：解释术语、帮用户读懂已显示的内容
- 付费 AI：针对已购买报告的追问、把报告内容对应到具体决策
- 不让免费 AI 直接回答「他会不会回来」「我该不该离职」这类高价值决策问题

> 这是产品决策，实际切法见 `PRD-ZH.md` / `PRD-JA.md` 与 `decisions/ADR-0003-ai-role.md`。

### 4.4 技术现状

- API：`/api/zh/interpret`、`/api/ja/interpret`
- 模型：DeepSeek（OpenAI 兼容）
- 护栏：origin、token、IP/token 限流、每日全域/IP 上限、输出 token 上限
- 已知限制：facts digest 只含部分宫位/星曜；AI 使用当前年份，不支持用户选的流年；限流是进程内计数

## 5. 内容与合规原则

1. **先共情，再解读**：先承认用户的处境，再给分析。
2. **不制造恐惧**：不用「不买会后悔」「今年有大灾」。
3. **不确定性要说清楚**：用「较容易」「可能」「主题」。
4. **免责要可见**：结果页/报告页/法务页。
5. **不编造社会证明**：没有真实见证就不放。
6. **价格与退款要清楚**：税、币别、退款条件。
7. **隐私**：生日资料只用于排盘；URL 参数/日志/分析工具要揭露。

细节：`content/TONE-AND-CLAIMS.md`。

---

## 6. 共通技术原则

- 排盘引擎 `lib/ziwei/*` 是两市场共用，**不要为单一市场改规则**；市场差异放在 `lib/zh/*` / `lib/jp/*`。
- 文案与页面各自独立，不互相 import 文案。
- 任何命理规则变更，必须有金标准盘与 `jp-patterns` / `zh-patterns` 回归。
- 付费解锁用 HMAC token；订单用 AES-GCM；webhook 用 HMAC 验签。
- 没有资料库前，不承诺「订单可查询/可退款自动化」。

## 7. 共通指标

| 指标 | 定义 |
|---|---|
| 诊断完成率 | 进入 `/shindan` → 成功产生结果 |
| 结果阅读深度 | 结果页停留/卷动/章节展开（待埋点） |
| 报告开启率 | 结果页 → 报告页 |
| 付费转化 | 报告页 → 完成付款 |
| AI 使用率 | 结果页 → AI 生成 |
| 退款率 | 付款后退款 / 付款 |
| 回访率 | 7/30 天内再次诊断或阅读 |

事件定义：`product/METRICS.md`。

## 9. 非目标（现在）

- 不做真人即时咨询
- 不做会员订阅制
- 不做 App（先 Web）
- 不做多语言自动切换（根路径固定 `/zh`）
- 不做命理师入驻平台
