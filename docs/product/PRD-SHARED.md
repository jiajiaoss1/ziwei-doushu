# 紫微館 PRD — 共同產品定義

> 這份文件只寫「跨市場不變的事」。
> 各市場的定位、定價、頁面與需求，見 `PRD-ZH.md` / `PRD-JA.md`。
> 未來韓語、越南語版新增 `PRD-KO.md` / `PRD-VI.md`，不修改本文件的市場假設。

---

## 1. 產品一句話

**用紫微斗數的命盤，幫使用者把「我現在卡住的事」看得更清楚，並給出可執行的下一步。**

不是「預測未來」，不是「保證靈驗」，也不是「通用 AI 聊天」。

---

## 2. 產品邊界

### 做

- 根據出生年月日、時刻、出生地排出紫微斗數命盤
- 把命盤轉成使用者能理解的語言（本質、感情、工作、金錢、大限、流年）
- 提供免費解讀與付費深度報告
- 提供相性、年度主題、文章等輔助內容
- 用 AI 做「受命盤事實約束」的追問與解釋

### 不做

- 醫療、法律、投資、賭博的專業建議
- 保證未來結果、命中率、一定復合/一定升職
- 用恐懼、詛咒、災難預言促使購買
- 編造使用者好評、假見證、假案例
- 未經同意的私訊/個資收集
- 把 `docs/tianji-ziwei/` 的原話大量翻譯或直接對外展示

---

## 3. 共通使用者旅程

```text
入口（首頁/文章/搜尋/社群）
  → 免費診斷（生日、時刻、出生地、煩惱/情境）
  → 結果頁（命盤、免費解讀、共情、AI 追問）
  → 付費報告（感情/事業；β 全免費）
  → 解鎖/付款
  → 售後（退款、客服、回訪）
```

每一段都必須回答一個問題：

| 階段 | 使用者問題 | 產品要給什麼 |
|---|---|---|
| 入口 | 這是什麼？跟我有關嗎？ | 一句話價值 + 具體情境 |
| 診斷 | 為什麼要填這些？ | 低摩擦、隱私說明、時間不明選項 |
| 結果 | 這在說我嗎？ | 具體、共情、可驗證的命盤依據 |
| 付費 | 為什麼要付？ | 免費沒給的決策/行動/時機 |
| 售後 | 買了之後呢？ | 可保存、可重讀、可退款/客服 |

## 4. AI 政策（跨市場）

### 4.1 AI 的角色

AI 不是「算命師」，是**解讀層**：

- 命盤由 `lib/ziwei/*` 確定性計算
- `facts` 層把命盤整理成結構化事實
- LLM 只根據這些事實，產生受約束的說明
- AI 不得新增命盤中不存在的星曜、宮位、四化

### 4.2 對外說法

可以說：

> 命盤由排盤引擎計算，AI 只根據這張命盤的事實來整理解讀。

不要說：

- 「比 ChatGPT 更準」
- 「AI 保證靈驗」
- 「命中率 98%」
- 「大師親算」（如果沒有真人）

### 4.3 免費/付費的 AI 邊界（方向）

- 免費 AI：解釋術語、幫使用者讀懂已顯示的內容
- 付費 AI：針對已購買報告的追問、把報告內容對應到具體決策
- 不讓免費 AI 直接回答「他會不會回來」「我該不該離職」這類高價值決策問題

> 這是產品決策，實際切法見 `PRD-ZH.md` / `PRD-JA.md` 與 `decisions/ADR-0003-ai-role.md`。

### 4.4 技術現狀

- API：`/api/zh/interpret`、`/api/ja/interpret`
- 模型：DeepSeek（OpenAI 兼容）
- 護欄：origin、token、IP/token 限流、每日全域/IP 上限、輸出 token 上限
- 已知限制：facts digest 只含部分宮位/星曜；AI 使用當前年份，不支援使用者選的流年；限流是進程內計數

## 5. 內容與合規原則

1. **先共情，再解讀**：先承認使用者的處境，再給分析。
2. **不製造恐懼**：不用「不買會後悔」「今年有大災」。
3. **不確定性要說清楚**：用「較容易」「可能」「主題」。
4. **免責要可見**：結果頁/報告頁/法務頁。
5. **不編造社會證明**：沒有真實見證就不放。
6. **價格與退款要清楚**：稅、幣別、退款條件。
7. **隱私**：生日資料只用於排盤；URL 參數/日誌/分析工具要揭露。

細節：`content/TONE-AND-CLAIMS.md`。

---

## 6. 共通技術原則

- 排盤引擎 `lib/ziwei/*` 是兩市場共用，**不要為單一市場改規則**；市場差異放在 `lib/zh/*` / `lib/jp/*`。
- 文案與頁面各自獨立，不互相 import 文案。
- 任何命理規則變更，必須有金標準盤與 `jp-patterns` / `zh-patterns` 回歸。
- 付費解鎖用 HMAC token；訂單用 AES-GCM；webhook 用 HMAC 驗簽。
- 沒有資料庫前，不承諾「訂單可查詢/可退款自動化」。

## 7. 共通指標

| 指標 | 定義 |
|---|---|
| 診斷完成率 | 進入 `/shindan` → 成功產生結果 |
| 結果閱讀深度 | 結果頁停留/捲動/章節展開（待埋點） |
| 報告開啟率 | 結果頁 → 報告頁 |
| 付費轉化 | 報告頁 → 完成付款 |
| AI 使用率 | 結果頁 → AI 生成 |
| 退款率 | 付款後退款 / 付款 |
| 回訪率 | 7/30 天內再次診斷或閱讀 |

事件定義：`product/METRICS.md`。

## 9. 非目標（現在）

- 不做真人即時諮詢
- 不做會員訂閱制
- 不做 App（先 Web）
- 不做多語言自動切換（根路徑固定 `/zh`）
- 不做命理師入駐平台
