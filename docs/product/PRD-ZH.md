## 2. Beachhead

### 首发人群

**30–42 岁、台湾女性，正在面对婚姻/长期关系重大决定，已经试过朋友、塔罗、宫庙/老师，仍不满意的人。**

具体情境：

- 外遇怀疑/第三者
- 分居
- 公婆/家庭界线
- 长期沟通疏离
- 离婚犹豫

不是：

- 所有对命理有兴趣的人
- 只想听“他会不会回来”的人
- 要外遇鉴定/法律建议的人
- 纯娱乐性算命

### 第二场景

30–45 岁转职/裁员人群：只做内容/后续验证，不进首发付费。

### 依据

- Threads 533 条合并数据 + 28 条 pilot
- 婚姻/长期关系比单纯分手更像付费场景
- 但 E3/E4 仍少，必须访谈验证

## 4. 痛点

Pilot 中反复出现：

1. 反复想、问朋友，还是没有答案
2. 一般星座/运势太笼统
3. 问 ChatGPT 也能得到一段话，但不知道该不该信
4. 怕被命理师推销、怕被恐吓
5. 怕花冤枉钱
6. 不知道该不该花钱、多少钱合理
7. 已付费但不知道怎么问/怎么用
8. 十个老师十种说法，越算越乱

> 详细定义见 `research/threads-codebook-v3.md`。

## 5. 定位

### 品类

**關係決策分析**

### 产品

**關係決策書**

### 承诺

> **幫你形成決定，也告訴你怎麼做。**

### 首页主标题

> **用命盤，把關係的混亂整理成可以做的決定。**

### 与通用 LLM 的差异

| 通用 LLM | 紫微馆 |
|---|---|
| 自由生成，说法可能每次不同 | 命盘由引擎固定计算 |
| 不知道你的命盘 | 以命盘事实为输入 |
| 倾向给果断答案 | 受约束、标示不确定性 |
| 不为决定负责 | 有方法、有边界、有免责 |

页面不强调 AI，用「科技輔助」；不声称比 ChatGPT 准。

### 与塔罗/宫庙的差异

- 不靠恐惧营销
- 不用“补人缘 3800”
- 价格透明
- 同一张盘可重复查看

## 6. 产品组合

| 产品 | 内容 | 价格 | 状态 |
|---|---|---|---|
| 免費關係決策自查 | 只收年月日；3 个判断 + 1 个建议 | 0 | planned |
| 規則化問題澄清 | 选情境 + 短文本，非自由聊天 | 0 | planned |
| **關係決策書** | 6 部分 + 命盘图 + 1–3 追问 | NT$680 早鸟 → NT$980 | planned |
| 相性診斷 | 两张命盘 | 0 | implemented |
| 2027 專題 | 流年主题 | 0 | implemented |
| 感情/事業鑑定書 | 旧报告 | — | legacy；不再作为首发主产品 |

### 免费/付费边界

| | 免费 | 付费 |
|---|---|---|
| 生辰 | 只收年月日 | 补时辰 + 出生县市 |
| 命盘 | 轻量/不完整 | 完整 |
| 解读 | 3 个判断 + 1 个建议 | 6 部分完整报告 |
| AI | 规则化澄清 | 报告后 1–3 追问，14 天 |
| 标注 | 「未含時辰，僅供初步整理」 | 时辰未知用午时，同价并标注 |

规则：

- 必须先做免费自查，才能购买
- 不做免费完整命盘解读
- 不做免费自由 AI 聊天
- 不做订阅
- 不做人工追问

## 7. 用户流程（目标）

```text
首页 / 内容 / Threads
  → 免費關係決策自查（年月日）
  → 自查結果（3 判斷 + 1 建議 + 未含時辰）
  → 付費（補時辰 + 縣市）
  → 關係決策書（網頁，立即生成，可回看 1 年）
  → 14 天內 1–3 個追問（AI，不轉人工）
```

### 与当前实现差距

- 当前 `/zh/shindan` 收年月日时/县市，是完整诊断，不是首发自查
- 当前 `/zh/result` 是免费完整体验，需改造成自查结果
- 当前 `/zh/report` 是感情/事业旧报告，不是 6 部分决策书
- 当前 ZH checkout 未实现
- 当前免费 AI 问答与付费边界重叠

> 具体页面改造进 SPEC；本 PRD 只定义目标。

## 8. 關係決策書（6 部分）

1. **决策问题**：你真正要决定的是什么
2. **关系模式**：命盘里反复出现的互动模式
3. **选项分析**：继续/谈/离开，各自代价与条件
4. **沟通脚本**：怎么开口、先问什么、设什么边界
5. **时机**：未来一段时间的主题，不是确定事件
6. **1–3 追问**：14 天内，AI 回答，不转人工

交付：

- 网页版，付款后立即生成
- 可回看 1 年（付款起算）
- 命盘图 + 只标注关键宫位
- 时区：台湾 UTC+8 / 120°E，真太阳时
- 时辰未知：午时推算并标注

## 9. 价格、退款、追问

- 早鸟 NT$680
- 恢复 NT$980
- 一次性购买，不做订阅
- 7 天内、未打开报告可退
- 追问 14 天，1–3 个（首次打开起算）
- AI 回答；敏感/超范围直接拒绝，不转人工
- 不知道时辰：同价，以午时推算并标注

---

## 10. AI 在繁中版

- 命盘由 `lib/ziwei/*` 计算
- LLM 只做受 facts 约束的解读
- 页面主文案不强调 AI，用「科技輔助」
- 方法说明/细字如实说明规则与边界
- 免费只做规则化澄清
- 付费报告后 1–3 追问
- 不允许：新增星曜/宫位/四化、保证结果、宣称命中率
- 详见 `ADR-0003`、`ai/AI-EVALUATION.md`
