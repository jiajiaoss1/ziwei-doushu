## 2. 目标人群（假设，待验证）

### Beachhead hypothesis

**正在关系里卡住、需要做决定的 28–40 岁港台用户。**

不是「所有对命理有兴趣的人」，而是：

- 正在经历分手、复合、暧昧、婚姻卡住
- 已经反复想很久，还是不知道要不要继续/怎么推进
- 愿意为「一个更清楚的判断」付 NT$680 级别的费用

### 第二优先

**30–45 岁、考虑转职/留任/创业的人。**
付费意愿可能更高（NT$980），但需要更强的专业信任与商业语言。

### 为什么不是所有人

- 免费诊断已经能满足「好奇」
- 没有具体决策的人，不会付费
- 同时打感情/工作/人际/自己，讯息会变模糊

> 这是 hypothesis。若 Threads 研究/访谈显示工作线更强，应调整。

## 3. JTBD（用户要完成的事）

### 感情线

> 当我卡在一段不确定的关系里，我想要知道「这段关系值不值得继续、接下来怎么走」，好让我不要再内耗，能做一个不后悔的决定。

### 工作线

> 当我考虑转职/留任/创业时，我想要知道「我的资质适合哪种路线、什么时机动比较好」，好让我不是凭焦虑做决定。

### 共同

> 我想要一个「不是通用星座运势」的个人化判读，而且它要能解释为什么。

## 4. 痛点（待研究验证）

1. 反复想、问朋友，还是没有答案
2. 一般星座/运势太笼统，不像在说自己
3. 问 ChatGPT 也能得到一段话，但不知道该不该信
4. 怕被命理师推销、怕被诅咒/恐吓
5. 不知道该不该花钱，也不知道多少钱合理
6. 付费后怕拿到「網路上也查得到」的通用内容

> 这些痛点需要用 `research/threads-pain-points-brief.md` 的真实语料验证/改写。

## 5. 定位与差异化

### 一句话

> **不是给你更多运势，而是帮你把一个卡住的决定看清楚。**

### 与通用 LLM 的差异

| 通用 LLM | 紫微馆 |
|---|---|
| 自由生成，说法可能每次不同 | 命盘由引擎固定计算，facts 固定 |
| 不知道你的命盘 | 以你的命盘事实为输入 |
| 倾向给出果断答案 | 受约束、不断定、标示不确定性 |
| 不为决定负责 | 有方法论、有边界、有免责 |

**不要对外说「比 ChatGPT 准」**；要说「命盘怎么算、依据什么、哪里不确定」。

### 与塔罗/一般占卜的差异

- 紫微斗数有明确的宫位/星曜/四化结构
- 报告能对应「哪个宫、哪颗星、哪个流年」
- 不是抽一张牌就结束

## 6. 产品组合

| 产品 | 内容 | 价格 | 状态 |
|---|---|---|---|
| 免费诊断 | 命盘、本质、感情、工作、今年主题 | 0 | implemented / beta |
| 感情鉴定书 | 对象、关系节奏、卡点、缘分时机、建议 | NT$680 / HKD160 | beta 全免费；付费未接 |
| 事业鉴定书 | 工作资质、职种、金钱、转机、行动 | NT$980 / HKD230 | beta 全免费；付费未接 |
| 相性诊断 | 两张命盘的吸引/错身 | 0 | implemented |
| 2027 专题 | 丁未年四化/主题 | 0 | implemented |
| AI 追问 | 基于命盘的回答 | 0（β） | beta |

### 免费/付费边界（方向）

- 免费：命盘 + 一份「理解」
- 付费：**决策 + 时机 + 行动 + 风险**（不是更多同质章节）
- β 期间全免费，是为了验证，不是最终形态

## 7. 用户流程

```text
首页 / 文章 / 社群
  → /zh/shindan（烦恼 + 情境 + 生日/时辰/县市）
  → /zh/result（共情、命盘、免费解读、AI 问答、报告入口）
  → /zh/report?type=love|work（β 全文）
  → 付款（未接）
  → 解锁（HMAC token）
```

### 已知流程问题

- 结果页的报告卡片没有显示价格
- 报告锁定区的「阅读全文」目前不是 checkout
- 感情报告锁定区写死成事业价格/链接（实现 bug，收费后会出现）
- 报告页切换类型时会丢失 `w`/`s` 情境参数，共情消失
- AI 免费问答可能替代付费报告

> 这些进 `REQUIREMENTS.md` / `BACKLOG.md`，不在 PRD 直接修。

## 9. AI 在繁中版

- 结果页可输入问题（200 字内）
- 基于命盘 facts + 系统 prompt
- 目前免费
- 风险：与付费报告功能重叠、回答可能被当成「决策建议」
- 方向：免费 AI 只解释；付费后才做决策追问（需 Owner 批准）

## 11. 风险

1. **免费版太完整**，付费动机不足
2. **AI 免费问答**替代付费报告
3. **报告通用**，付费后觉得不值
4. **没有真实社会证明**，信任不足
5. **法务主体/客服/退款**未完成
6. **定价**未经测试
7. **Threads 样本偏差**，不能代表全市场
