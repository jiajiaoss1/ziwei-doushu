## 2. 目標人群（假設，待驗證）

### Beachhead hypothesis

**正在關係裡卡住、需要做決定的 28–40 歲港台使用者。**

不是「所有對命理有興趣的人」，而是：

- 正在經歷分手、復合、曖昧、婚姻卡住
- 已經反覆想很久，還是不知道要不要繼續/怎麼推進
- 願意為「一個更清楚的判斷」付 NT$680 級別的費用

### 第二優先

**30–45 歲、考慮轉職/留任/創業的人。**
付費意願可能更高（NT$980），但需要更強的專業信任與商業語言。

### 為什麼不是所有人

- 免費診斷已經能滿足「好奇」
- 沒有具體決策的人，不會付費
- 同時打感情/工作/人際/自己，訊息會變模糊

> 這是 hypothesis。若 Threads 研究/訪談顯示工作線更強，應調整。

## 3. JTBD（使用者要完成的事）

### 感情線

> 當我卡在一段不確定的關係裡，我想要知道「這段關係值不值得繼續、接下來怎麼走」，好讓我不要再內耗，能做一個不後悔的決定。

### 工作線

> 當我考慮轉職/留任/創業時，我想要知道「我的資質適合哪種路線、什麼時機動比較好」，好讓我不是憑焦慮做決定。

### 共同

> 我想要一個「不是通用星座運勢」的個人化判讀，而且它要能解釋為什麼。

## 4. 痛點（待研究驗證）

1. 反覆想、問朋友，還是沒有答案
2. 一般星座/運勢太籠統，不像在說自己
3. 問 ChatGPT 也能得到一段話，但不知道該不該信
4. 怕被命理師推銷、怕被詛咒/恐嚇
5. 不知道該不該花錢，也不知道多少錢合理
6. 付費後怕拿到「網路上也查得到」的通用內容

> 這些痛點需要用 `research/threads-pain-points-brief.md` 的真實語料驗證/改寫。

## 5. 定位與差異化

### 一句話

> **不是給你更多運勢，而是幫你把一個卡住的決定看清楚。**

### 與通用 LLM 的差異

| 通用 LLM | 紫微館 |
|---|---|
| 自由生成，說法可能每次不同 | 命盤由引擎固定計算，facts 固定 |
| 不知道你的命盤 | 以你的命盤事實為輸入 |
| 傾向給出果斷答案 | 受約束、不斷定、標示不確定性 |
| 不為決定負責 | 有方法論、有邊界、有免責 |

**不要對外說「比 ChatGPT 準」**；要說「命盤怎麼算、依據什麼、哪裡不確定」。

### 與塔羅/一般占卜的差異

- 紫微斗數有明確的宮位/星曜/四化結構
- 報告能對應「哪個宮、哪顆星、哪個流年」
- 不是抽一張牌就結束

## 6. 產品組合

| 產品 | 內容 | 價格 | 狀態 |
|---|---|---|---|
| 免費診斷 | 命盤、本質、感情、工作、今年主題 | 0 | implemented / beta |
| 感情鑑定書 | 對象、關係節奏、卡點、緣分時機、建議 | NT$680 / HKD160 | beta 全免費；付費未接 |
| 事業鑑定書 | 工作資質、職種、金錢、轉機、行動 | NT$980 / HKD230 | beta 全免費；付費未接 |
| 相性診斷 | 兩張命盤的吸引/錯身 | 0 | implemented |
| 2027 專題 | 丁未年四化/主題 | 0 | implemented |
| AI 追問 | 基於命盤的回答 | 0（β） | beta |

### 免費/付費邊界（方向）

- 免費：命盤 + 一份「理解」
- 付費：**決策 + 時機 + 行動 + 風險**（不是更多同質章節）
- β 期間全免費，是為了驗證，不是最終形態

## 7. 使用者流程

```text
首頁 / 文章 / 社群
  → /zh/shindan（煩惱 + 情境 + 生日/時辰/縣市）
  → /zh/result（共情、命盤、免費解讀、AI 問答、報告入口）
  → /zh/report?type=love|work（β 全文）
  → 付款（未接）
  → 解鎖（HMAC token）
```

### 已知流程問題

- 結果頁的報告卡片沒有顯示價格
- 報告鎖定區的「閱讀全文」目前不是 checkout
- 感情報告鎖定區寫死成事業價格/連結（實作 bug，收費後會出現）
- 報告頁切換類型時會丟失 `w`/`s` 情境參數，共情消失
- AI 免費問答可能替代付費報告

> 這些進 `REQUIREMENTS.md` / `BACKLOG.md`，不在 PRD 直接修。

## 9. AI 在繁中版

- 結果頁可輸入問題（200 字內）
- 基於命盤 facts + 系統 prompt
- 目前免費
- 風險：與付費報告功能重疊、回答可能被當成「決策建議」
- 方向：免費 AI 只解釋；付費後才做決策追問（需 Owner 批准）
