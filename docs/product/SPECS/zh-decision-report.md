# SPEC：關係決策書

> 目标产品，不代表已实现。
> 依据：`ADR-0007`、`PRD-ZH.md`、`POSITIONING.md`。

---

## 1. 目标用户 / 问题

**用户**

- 30–42 岁台湾女性
- 正在面对婚姻/长期关系重大决定
- 已试过朋友、塔罗、宫庙/老师，仍不满意
- 想决定：继续 / 谈 / 离开，以及怎么谈

**问题**

- 资讯很乱，十个老师十种说法
- 怕被坑、怕花冤枉钱
- 已付费但不知道怎么问/怎么用
- 想要一个可判断的选项，不是更多预测

---

## 2. 范围

### 做

- 免费关系决策自查（只收年月日）
- 自查结果：3 个判断 + 1 个下一步建议
- 付费补时辰 + 出生县市
- 6 部分网页报告
- 命盘图 + 关键宫位标注
- 付款后立即生成
- 报告可回看 1 年
- 14 天内 1–3 个追问（AI）
- 7 天内未看全文可退

### 不做

- 外遇鉴定/抓小三
- 法律/医疗/心理治疗
- 保证复合/离婚/结婚结果
- 免费完整命盘解读
- 免费自由 AI 聊天
- 订阅
- 人工追问
- HK 首发

---

## 3. 流程

```text
/zh 首页
  → 關係決策自查（年月日 + 關係狀態 + 想決定什麼 + 試過什麼）
  → 自查結果（3 判斷 + 1 建議 + 未含時辰）
  → 付款頁（補時辰 + 縣市）
  → NT$680 早鳥 / NT$980
  → 付款成功
  → 立即生成
  → 網頁報告（1 年）
  → 14 天內 1–3 追問
```

### 3.1 自查输入

必填：

- 出生年/月/日
- 关系状态：交往/同居/已婚/分居/离婚考虑
- 最想决定的事（单选 + 短文本）
- 已试过什么（多选：朋友/塔罗/宫庙/老师/ChatGPT/自己查）

不收：

- 出生时辰
- 出生县市
- 对方生辰

### 3.2 自查结果

固定 3 个判断 + 1 个建议：

1. 你现在最像在决定什么
2. 你最常卡住的模式
3. 你下一步最该先确认什么
4. 建议：先做/先问/先停

必须标注：

> 未含時辰，僅供初步整理；補上時辰後，命盤與解讀會更完整。

### 3.3 付费输入

- 出生时辰（可不知道 → 午时）
- 出生县市（必填，真太阳时）
- 关系状态/决策问题可修改
- 不要求对方生辰

### 3.4 生成

- 付款成功后立即生成
- 先生成确定性骨架，再填充解读
- AI 只使用 facts digest，不得新增星曜/宫位/四化
- 生成失败：显示重试；连续失败进入退款/客服流程

## 4. 报告结构

### 标题

> 你的關係決策書

### 4.1 你真正要決定的是什麼

- 复述用户情境
- 把“他会不会…”转成“你要不要…”
- 给 1 个决策句

### 4.2 命盤裡反覆出現的關係模式

- 3 个模式
- 每个模式必须对应：宫位/星曜/四化
- 不给“命中率”
- 空宫必须写“借對宮”或明确“空宮”

### 4.3 三個選項，各自的代價

固定三选：

- 繼續
- 談/設界線
- 離開/暫停

每个写：

- 适合条件
- 代价
- 下一步

不替用户做选择。

### 4.4 怎麼開口：溝通腳本與界線

- 3 段可复制的开场/追问/设界线
- 不教操控、不教查手机
- 遇到暴力/危险：建议求助专业资源

### 4.5 時機：接下來的節奏

- 未来 6–12 个月主题
- 用“较容易/需要留意”，不用“一定会”
- 不给具体事件日期

### 4.6 你还可以問的三個問題

- 根据报告生成 3 个建议追问
- 14 天内可用
- 敏感/超范围拒绝

### 页脚

> 本報告以命盤事實與規則整理，屬自我理解與決策參考，不是外遇鑑定、法律、醫療或心理治療建議，也不保證結果。

---

## 5. 边界与错误

| 情况 | 处理 |
|---|---|
| 时辰未知 | 午时推算，同价，报告标注 |
| 县市未知 | 必填；不知道选最近城市，标注 |
| 用户要判断第三者 | 不做鉴定；改成“你能确认的事实/你能问的问题” |
| 用户要法律/医疗建议 | 拒绝，给求助方向 |
| 用户要保证复合 | 明确不保证 |
| 暴力/危险 | 给求助资源，不继续命理分析 |
| AI 生成失败 | 重试；连续失败退款/客服 |
| 付款失败 | 不生成、不扣解锁 |
| 报告未看 | 7 天内可退 |
| 报告已看 | 不退；可客服申诉 |
| 追问超范围 | 拒绝并说明边界 |
| 追问超过 14 天 | 关闭，提示已过期 |

## 6. 文案

### 首页主标题

> 用命盤，把關係的混亂整理成可以做的決定。

### 付费 CTA

> 取得我的關係決策書

### 免费结果 CTA

> 補上時辰，取得完整關係決策書

### 价值句

> 幫你做決定，也告訴你怎麼做。

### 信任草案（非真实评价）

> 我本來只想問「他會不會回來」，報告卻先幫我看清楚：我真正要決定的是要不要繼續。

## 8. 测试

### 内容

- 6 部分都存在
- 每个模式对应宫位/星曜/四化
- 空宫有借对宫/空宫说明
- 没有“一定/保证/命中率”
- 没有医疗/法律/外遇鉴定
- 时辰未知有标注
- 时区/真太阳时正确

### 流程

- 自查 → 结果 → 付费 → 生成 → 报告
- 未做自查不能买
- 付款失败不生成
- 生成失败可重试/退款
- 报告 1 年访问
- 追问 14 天过期
- 追问不转人工
- 7 天未看全文可退
- 已看全文不可退
